# Review-Python

        Entender o problema e estruturar as pastas do projecto

3-	Estruturas de repetição e o format
        continuacao do ponto dois permitindo que o mesmo codigo seja executado varias vezes. e tratamento de texto

4-	Estruturas de Condição e textos em python

5-	Trabalhando com tabelas e base de dados em python
        Introdução a biblioteca Pandas

6-	Indicadores e Gráficos em python
